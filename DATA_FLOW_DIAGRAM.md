### 1. Frontend to Backend (Invoice Save)
```
JavaScript Object:
{
  customerId: number,
  subTotal: number,
  gstAmount: number,
  grandTotal: number,
  items: [
    { productId, quantity, rate, amount },
    ...
  ]
}
       ?
       ?
API Call: POST /api/invoices/save
       ?
       ?

{
  CustomerId: int,
  SubTotal: decimal,
  GSTAmount: decimal,
  GrandTotal: decimal,
  Items: List<CreateInvoiceItemDto>
```

## State Management

### GenerateInvoice Component
- `pricingData`: Product pricing list
- `selectedType`: Filter by product type
- `selectedProductId`: Currently selected product
- `invoiceItems`: Array of items added to invoice
- `subTotal`, `gst`, `grandTotal`: Calculated totals

### InvoicePreview Component
- `invoice`: Full invoice data from database
- `loading`: Loading state during data fetch
- `downloading`: Downloading state for PDF
- `error`: Error message if fetch fails

---

**All data flows from database through typed DTOs ensuring type safety and data integrity throughout the system.**
